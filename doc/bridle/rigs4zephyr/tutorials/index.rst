Tutorials
=========

Guided, hands-on lessons that build the rig model up one concept at a
time. They follow one running story: **Rae**, a firmware developer at ACME
Robotics, starting from a bare NUCLEO board and ending with a bench rig.

Each page introduces exactly one new idea and depends on the one before
it, so read them in order the first time. Every page states its
prerequisites, and any page describing functionality that has not shipped
yet opens with a warning saying so.
